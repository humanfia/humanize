# `runtime/watching`

A run read as it happens, as every frontend reads it: who is working and who handed to whom,
what each model has cost, and the bounded view of it a side question is asked with -- worked
out of the records a host sends and the logs its agents keep, and asked of nothing else.

## API

```python
# monitor.py -- the graph of a run, and its bill per model
@dataclass

    def counted(self, source: str, model: str, total: int, now: float | None = None,
                kinds: Mapping[str, float] | None = None) -> None: ...
    def reporting(self, agent: str, kinds: Iterable[str]) -> None: ...
    def stirring(self) -> None: ...
    def stops(self) -> None: ...
    def spending(self, now: float | None = None) -> list[Spend]: ...
    def reckoning(self, now: float | None = None) -> list[Counted]: ...
    def now_working(self) -> list[str]: ...
    def shape(self, *, sessions: bool = False) -> Shape: ...
class Shape: ...  # turns, working, handovers, under, since, latest, used
class Spend: ...  # model, tokens, rate, dollars (None where nobody prices it), kinds
class Counted: ...  # kind, tokens, whole (False where it is a floor)

def lasting(seconds: float) -> str: ...
def thousands(count: float) -> str: ...
def short(agent: str) -> str: ...
def tallied(monitor: Monitor) -> tuple[str, str] | None: ...  # the kinds line, the money line
# tally.py -- what a run has spent, read off the logs its agents keep
class Seen: ...  # one session: id, backend, model, counts, idents, kept, since
class Tally:
    def __init__(self, sessions: Sequence[Seen], monitor: Monitor) -> None: ...
    def add(self, session: Seen) -> None: ...

# following.py -- the runs one frontend follows, from the records its host sends
class Following:

    def heard(self, record: Mapping[str, Any]) -> str | None: ...
    def printed(self, text: str) -> None: ...
    def ended(self, record: Mapping[str, Any]) -> None: ...
    def snapshot(self, *, flow: str, task: str, workspace: str, going: bool,
                 working: Collection[str], waiting: int,
                 waiting_for_input: bool) -> FlowSnapshot: ...
# btw.py -- side questions, asked beside a run and never of it
HOPS: int  # 4
class FlowSnapshot: ...  # frozen; AgentProgress and Observation are its parts
def format_snapshot(snapshot: FlowSnapshot, question: str, *, about: str = "") -> str: ...
def format_forked(key: str, question: str) -> str: ...
```

## Requirements

- MUST be the one place a run is worked out as it happens: every frontend MUST draw the same
  figures of one run, and MUST NOT work any of them out a second time.
- MUST work a run out of what its host tells a frontend and the logs its agents keep alone,
  MUST name nothing above `coganchor`, and MUST start no agent but through the side
  conversations it is handed a way to ask for.
- MUST count each turn against the agent and the conversation that took it, an agent a turn
  started of its own as working under it, and each handover from the agent that last finished
  a turn to the next to begin one.
- MUST say what each model cost in money where it is priced and in tokens alone where it is
  not, never reading a missing price as nothing; MUST say what went on each kind of token over
  the whole run, marking a figure as a floor where an agent's CLI does not count that kind; and
  MUST divide a turn that named two models by what each took rather than drop it.
- MUST read what a session spends off the log its CLI keeps as the turn goes, and read it once
  more as the run ends; a run stopped and unwinding behind the next MUST be counted until it
  ends, against its agents alone and never against the conversations of the run in front.
- `lasting` MUST say a clock as every frontend says it: seconds under a minute, minutes and
  seconds under an hour, hours and minutes above.
- What a side question is told MUST be bounded, MUST be the run in front alone -- what its
  agents did and said, and what its flow printed -- MUST leave out an agent's thinking, and
  MUST start empty with each run.
- A side question MUST go to a side conversation and never to the run: in a conversation's
  name, to a read-only fork of it where its CLI forks one, and where the fork will not open or
  will not answer, to a copy of its agent told the snapshot; otherwise to the btw agent, told
  the snapshot and the conversations it may ask by `@ask <conversation>: <question>`, at most
  `HOPS` of them on one question, each answered back to it.
- The btw agent MUST be the agent `/settings` names; else the flow's first role, as its first
  conversation where it has one or as the agent it runs as; else the run's first conversation;
  and none where there is none of these.
- A mode left MUST close every side conversation it opened, and one that opens after it was
  left MUST be closed at once, the question that opened it raising `Left`.

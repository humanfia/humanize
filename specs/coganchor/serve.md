# `coganchor/serve`

The target half of an anchored session: carrying out on this machine the filesystem operations,
the commands and the outbound connections a client asks for over the wire. An authorisation
boundary over paths and nothing more — not a sandbox, and knowing nothing of agents or accounts.

## API

```python
# exports.py -- which of this machine's paths a connection may name
INSENSITIVE: bool   # whether this machine folds case in a path

@dataclass(frozen=True, slots=True)
class Export:
    virtual: str
    real: str
    @classmethod
    def parse(cls, spec: str) -> Export: ...   # "VIRTUAL[:REAL]"

class ExportTable:
    def __init__(
        self, exports: list[Export], *, insensitive: bool = INSENSITIVE
    ) -> None: ...
    @classmethod
    def parse(cls, specs: list[str], *, insensitive: bool = INSENSITIVE) -> ExportTable: ...
    @property
    def exports(self) -> list[Export]: ...
    def resolve(self, virtual: str) -> str: ...
    def rewrite(self, text: str) -> str: ...

# fsops.py -- the operations themselves, each answering a description of what it touched
# and raising this machine's own OSError
def describe(real: str, *, name: str | None = None) -> dict[str, Any]: ...
def stat(table: ExportTable, path: str) -> dict[str, Any]: ...
def listdir(table: ExportTable, path: str) -> dict[str, Any]: ...
def read(
    table: ExportTable, path: str, emit: Callable[[bytes], None]
) -> dict[str, Any]: ...
def mkdir(
    table: ExportTable, path: str, mode: int, *, parents: bool
) -> dict[str, Any]: ...
def rmdir(table: ExportTable, path: str) -> dict[str, Any]: ...
def unlink(table: ExportTable, path: str) -> dict[str, Any]: ...
def rename(
    table: ExportTable, src: str, dst: str, *, replace: bool
) -> dict[str, Any]: ...
def symlink(table: ExportTable, target: str, path: str) -> dict[str, Any]: ...
def link(table: ExportTable, src: str, dst: str) -> dict[str, Any]: ...
def readlink(table: ExportTable, path: str) -> dict[str, Any]: ...
def chmod(table: ExportTable, path: str, mode: int) -> dict[str, Any]: ...
def truncate(table: ExportTable, path: str, size: int) -> dict[str, Any]: ...
def utime(
    table: ExportTable, path: str, atime_ns: int | None, mtime_ns: int | None
) -> dict[str, Any]: ...

class FileWriter:
    def __init__(self, table: ExportTable, path: str, mode: int | None) -> None: ...
    def feed(self, data: bytes) -> None: ...
    def finish(self) -> dict[str, Any]: ...
    def abort(self) -> None: ...

# sessions.py -- what runs for as long as the request that started it
def compose_env(remote_env: dict[str, str], cwd: str, *, tty: bool) -> dict[str, str]: ...

class Session:
    def __init__(self, msg_id: int, channel: Channel) -> None: ...
    def start(self) -> None: ...
    def feed(self, stream: Stream, data: bytes) -> None: ...
    def end_input(self, stream: Stream) -> None: ...
    def shutdown(self) -> None: ...
    def join(self, timeout: float | None = None) -> None: ...

class ExecSession(Session):
    def __init__(
        self,
        msg_id: int,
        channel: Channel,
        table: ExportTable,
        request: dict[str, Any],
    ) -> None: ...
    def signal(self, signum: int) -> None: ...

class TunnelSession(Session):
    def __init__(self, msg_id: int, channel: Channel, request: dict[str, Any]) -> None: ...

# server.py -- one connection
class Server:
    def __init__(
        self, channel: Channel, table: ExportTable, token: str | None = None
    ) -> None: ...
    def serve(self) -> None: ...
    def close(self) -> None: ...

# listener.py -- many
def serve_forever(host: str, port: int, table: ExportTable, token: str | None) -> None: ...
```

## Requirements

- MUST name `hmz.coganchor.proto` and nothing else of `hmz.coganchor`.
- MUST run on any POSIX system with a Python of the vintage the anchoring half needs, on either
  architecture, needing no root, no compiler, no kernel module and nothing installed.
- MUST refuse a request naming a path no export covers, and any request arriving before a
  handshake it accepted.
- MUST refuse, and close the connection with, a peer speaking another protocol version or
  presenting anything but the token it was started with.
- MUST answer a failed operation with this machine's own errno and message.
- MUST reach the same file by every spelling this machine has for its path.
- MUST replace a file whole or not at all, leaving what was there if a write does not finish.
- MUST answer other requests while a command it started runs, stream that command's output as
  it arrives, and report its exit status and the signal that ended it.
- MUST end every process and tunnel it started when the connection ends, and MUST serve many
  connections at once when told to listen on a port.
- MUST NOT be taken for a sandbox: an export bounds which paths a request may name and
  confines neither the commands a request runs nor a symlink out of the tree, so a listening
  port is equivalent to a shell on that machine.

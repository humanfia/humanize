# Tutorials

Each tutorial walks through one job from start to finish. Follow the steps in order to see the expected output at each stage. If you are new, start with the first tutorial in either list.

## Using Humanize

Run agents with Humanize Desktop, the browser page, the terminal or the command line.

- [Finish your first task in Humanize Desktop](/tutorials/first-task-desktop): install the app, add an account, chat and run a flow on a small task with a budget.
- [Finish your first task in the terminal](/tutorials/first-task-terminal): install the CLI, open `hmz`, install a flow, give it a task and read the output.
- [Use Humanize from a browser and your phone](/tutorials/browser-and-phone): open the page with `hmz web`, reach it from your phone and pair a second machine.
- [Leave a long task running overnight](/tutorials/overnight-run): set a time and cost budget, leave the task running and review what it did.
- [Run two coding agents with a fallback](/tutorials/two-agents-with-fallback): set up two coding agents and build a virtual nous that falls back from one to the other.
- [Run the work on a server or in a container](/tutorials/work-on-a-server): point a chat or an epic at an SSH host or a Docker container.
- [Run a flow every night in CI](/tutorials/nightly-in-ci): run `hmz exec` in GitHub Actions and save the epic as an artifact.
- [Read back, export and share a run](/tutorials/read-back-a-run): open a finished epic, read its trace and usage, export it and back it up.

## Building flows

Write flows in Python.

- [Write your first flow](/tutorials/first-flow): write a flow file with one agent and a loop, then run it from the command line and the app.
- [Build an actor–reviewer loop under test](/tutorials/review-loop): combine two roles and a typed verdict, testing first against fake agents.
- [Build a flow that asks you](/tutorials/ask-the-person): ask a question with a form, answer it in the app and the terminal, and stand in for the person in tests.
- [Fan out agents across git worktrees](/tutorials/parallel-worktrees): run agents in parallel in separate worktrees and keep the best one.
- [Publish a flow to a flowverse](/tutorials/publish-a-flow): add a manifest, cut a release and install the flow from a flowverse.
- [Drive Humanize from Python](/tutorials/drive-from-python): start a flow from a script, follow its events and answer its questions.
